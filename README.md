# NUAR — інтернет-магазин (версія для хостингу)

Що вміє: каталог, кошик, замовлення, **листи клієнту і вам з nuar.magazin.ua@gmail.com**,
**підказки міст і відділень Нової Пошти**, адмін-панель (товари, тексти, фото, оплата).

## Запуск на Vercel (безкоштовно), ~15 хвилин

1. Створіть акаунт на github.com і новий репозиторій, завантажте в нього **вміст цієї папки**
   (папки `api`, `public` і файл `package.json`).
2. На vercel.com натисніть **Add New → Project**, виберіть цей репозиторій, **Deploy**.
3. У проєкті відкрийте **Storage → Create / Marketplace → Upstash Redis** (безкоштовний план)
   і підключіть до проєкту. Це база, де зберігаються ваші товари й тексти.
4. **Settings → Environment Variables**, додайте:

| Назва | Значення |
|---|---|
| `ADMIN_PASSWORD` | ваш пароль для входу в адмінку (придумайте довгий) |
| `GMAIL_USER` | `nuar.magazin.ua@gmail.com` |
| `GMAIL_APP_PASSWORD` | пароль додатка Gmail (нижче) |
| `NOVA_POSHTA_API_KEY` | ключ API Нової Пошти (нижче) |
| `OWNER_EMAIL` | (необов'язково) куди надсилати нові замовлення; за замовчуванням на Gmail магазину |

5. Після додавання змінних зробіть **Deployments → Redeploy**.

### Пароль додатка Gmail
Акаунт Google → Безпека → увімкніть **двоетапну перевірку** → «Паролі додатків» → створіть пароль
для «Пошта». Це 16 символів, **не ваш звичайний пароль**. Вставте їх лише в Vercel, нікому не надсилайте.

### Ключ API Нової Пошти
Особистий кабінет business.novaposhta.ua → Налаштування → Безпека → **Ключі API** → створити.

## Як керувати сайтом
- Відкрийте `https://ваш-сайт/#admin` і введіть пароль. З'явиться кнопка «Адмін» у меню.
- «Редагувати сайт»: тексти, фото, контакти, оплата (картка, посилання на банку monobank/LiqPay).
- Товари: додавання, зміна, порядок, приховування, видалення.
- **Перший раз** після запуску натисніть «Редагувати сайт» → «Зберегти» (це збереже каталог у базі,
  щоб сервер брав ціни з нього, а не з браузера клієнта).

## Свій домен
Vercel → Settings → Domains → додайте домен (наприклад nuar.com.ua) і виконайте інструкцію.

## Перевірка після запуску
Зробіть тестове замовлення зі своєю поштою: має прийти лист клієнту і лист вам.
У полі «Місто» мають з'явитися підказки Нової Пошти, а після вибору міста, у полі відділення, їх список.
Якщо підказок немає, перевірте `NOVA_POSHTA_API_KEY` (Vercel → Logs).
